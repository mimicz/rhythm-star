# 🌟 節奏小星星 Rhythm Star

一款適合國小學童的網頁節奏遊戲。**單一 HTML 檔案、零外部相依、開啟即玩**，音樂全部由瀏覽器即時合成。

## 🎮 線上遊玩

👉 **https://mimicz.github.io/rhythm-star/**

手機、平板、電腦皆可遊玩，不需安裝任何東西。

## ✨ 特色

- **五首曲目** — 小星星、兩隻老虎、瑪莉的小綿羊、生日快樂（皆為公版童謠），以及原創曲「彩虹節奏」
- **三種難度** — 簡單（2 軌）／普通（3 軌）／挑戰（4 軌）
- **練習模式** — 可放慢到 0.75x 或 0.5x，不計入成績，適合初學者
- **兒童友善判定** — 判定窗刻意放寬（完美 ±0.125 秒、不錯 ±0.235 秒），不會一直 Miss
- **成績與排行榜** — 以 `localStorage` 保存，支援玩家名稱、每首歌前五名
- **關卡解鎖** — 通關一首解鎖下一首；老師可用「全部解鎖」按鈕直接開放
- **觸控 + 鍵盤** — 手機直接點大按鈕；電腦可用 `D` `F` `J` `K` 或方向鍵，`Esc` 暫停

## 🎵 音樂與版權

所有音樂皆由程式以 **Web Audio API 即時合成**（三角波旋律 + 大鼓 + Hi-Hat），沒有任何音訊檔案。
曲目為公版童謠與原創曲，**可安心用於教學與公開場合**。

## 🛠 技術說明

- 純前端單檔（`index.html`），HTML + CSS + Canvas 2D + Web Audio API
- 無框架、無建置流程、無外部 CDN 相依
- 主時鐘優先使用 `AudioContext.currentTime` 以確保譜面與聲音不會飄移；
  若瀏覽器封鎖音訊，會自動切換成系統時鐘，遊戲仍可無聲遊玩
- 譜面由旋律資料即時推導：依音高映射到軌道，並避免同軌連續超過兩顆音符
- 支援高 DPI 螢幕（DPR 上限 2）與 iOS safe-area

## 🔊 沒有聲音怎麼辦？

瀏覽器（尤其 Chrome）規定音訊必須由使用者操作啟動。首頁有 **🔊 音效測試** 按鈕可先確認。
若仍無聲，請檢查：分頁是否被靜音、瀏覽器網站設定中的「音效」是否被封鎖，或改用 Edge 開啟。
